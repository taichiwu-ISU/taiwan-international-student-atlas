教育統計 / 作者資訊

吳岱栖

義守大學國際策略長

美國密西西比州立大學（Mississippi State University）工業工程博士，曾任學生事務長、國際及兩岸事務處處長，具備豐富的高等教育行政管理、國際事務推動及跨單位整合經驗。

長期致力於高等教育國際化發展，曾擔任教育部「新南向及非洲計畫專案辦公室」執行長，推動臺灣高等教育與新南向國家及非洲地區的教育交流、國際招生、學術合作及人才培育，積極促進臺灣高等教育的國際連結與影響力。在校務行政方面，重視國際化策略、跨文化交流及國際學生支持體系的建立，致力於打造多元共融的國際化校園。

擔任義守大學學生事務長期間，積極推動以學生為中心的教育創新與全人發展，規劃建置「Well-being Center」，整合心理健康、身體健康、學習支持及職涯發展等資源，建構跨單位合作的學生支持體系。同時，推動開設「University 101（大學101）」課程，結合新生適應、社會情緒學習（SEL）、自我探索、生涯規劃及自主學習，協助大一新生順利銜接大學生活，培養自我管理能力、人際關係與校園歸屬感，提升整體學習經驗與學生福祉。

本站由吳岱栖規劃，並由義守大學國際處團隊製作。
